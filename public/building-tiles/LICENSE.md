# Edificios complementarios del Atlántico

Huellas de edificios de Microsoft Global ML Building Footprints (https://github.com/microsoft/GlobalMLBuildingFootprints), distribuidas bajo Open Data Commons Open Database License (ODbL) 1.0. Solo se incluyen las que no se cruzan con un edificio de OpenStreetMap (© OpenStreetMap contributors, ODbL).

Generado con `scripts/build-building-tiles.mjs` el 2026-11-25. Las huellas se detectaron automáticamente en imágenes satelitales y pueden tener errores.
